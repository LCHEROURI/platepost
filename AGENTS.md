# Standing instruction from Larry (project owner)

For building apps, use the Google ecosystem by default, unless Larry instructs otherwise. Prefer Google Cloud / Firebase services for backend, database, authentication, hosting, and other platform needs — for example Firebase Auth, Firestore, Firebase Hosting, Google Cloud Run, and Google Maps APIs — over non-Google alternatives. If a task seems to need a non-Google service, ask Larry first instead of assuming. This rule applies to all new work in this project; it does not retroactively change existing choices unless Larry asks.
